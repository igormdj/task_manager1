# Exercícios Diários de Lógica de Programação em Ruby (30 dias)

Este diretório contém exercícios diários para você praticar **lógica de programação em Ruby**, do **básico ao avançado**, com foco em fixar conceitos.

## Como usar
1. Escolha o dia atual (ou qualquer dia).
2. Abra o arquivo correspondente: `dia_XX.rb`.
3. Leia o enunciado e restrições.
4. Preencha a seção **"SUA SOLUÇÃO"**.
5. Quando quiser comparar, veja a seção **"REFERÊNCIA (COMENTADA)"**.

## Dica de estudo (recomendado)
- Tente resolver sem olhar a referência.
- Se travar, volte às entradas/saídas e revise o raciocínio (não o código).
- Depois valide manualmente com os exemplos.

## Organização dos dias
- **Dia 01-10:** básico (if/else, loops, arrays)
- **Dia 11-20:** intermediário (map/select/reduce, hashes, palíndromo, fatorial, Fibonacci)
- **Dia 21-30:** avançado (recursão, memoização, busca/ordenação, parsing/validações, eficiência)
